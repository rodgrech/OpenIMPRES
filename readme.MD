# OpenIMPRES

Open-source ESP32-based Motorola IMPRES battery monitoring and charger integration.

Read battery health, charge state, cycle count and charger telemetry from IMPRES batteries and chargers.

Features:
- Single-bay charger support
- Multi-unit charger support
- MQTT / Home Assistant integration
- Local TFT display support
- Battery health / EOL monitoring
- Reverse engineering notes for Motorola Battery Reader compatibility
